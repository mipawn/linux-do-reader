# LINUX DO 阅读器

适用于 ego lite、Chrome 和 Edge 的第三方浏览器扩展。左边浏览话题，右边阅读主帖和按回复关系展开的楼层。

- **默认阅读器**：打开或刷新 Linux.do 浏览页即可阅读，随时切回原版。
- **真实阅读同步**：按实际可见楼层同步原站阅读进度和未读标记，不刷阅读量。
- **双栏与回复树**：浏览话题、阅读回复、收藏和管理关注。
- **保留浏览器习惯**：支持 `⌘/Ctrl + 点击` 新标签页，以及原站的通知和聊天入口。

## 安装

1. 从[最新版本](https://github.com/mipawn/linux-do-reader/releases/latest)下载版本安装包（例如 `linux-do-reader-1.6.0.zip`）并解压。在 macOS 上，可以把解压后的文件夹放在 `~/Library/Application Support/Linux DO Reader`，目录里应直接包含 `manifest.json`。
2. 在 ego lite 或 Chrome 打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`。
3. 打开「开发者模式」，点「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。在 macOS 的文件选择窗口可以用 `⌘⇧G` 输入目录路径。
4. 打开或刷新 Linux.do 的首页、话题或列表页，默认进入阅读器。论坛页头有「阅读器 / 原版」切换，也可从浏览器扩展菜单打开阅读器。登录、账号设置和发帖等操作页保留原版。

ZIP 可以在解压后删除。浏览器会从选中的文件夹读取扩展文件，需要保留该文件夹。移动安装目录时，先停用旧条目，再加载新位置。确认新版可用后，可以移除旧条目并删除旧目录。

以后更新时，把新版文件覆盖到已经加载的固定目录。在扩展管理页点该扩展的「重新加载」，然后刷新 Linux.do。

## 使用

- 顶部可切换话题、收藏、关注。「最新」下拉可以换话题列表，「筛选」可组合类别和标签，按 `/` 聚焦搜索框。
- 顶部「原站导航」包含社区、资源、类别、标签和自定义项目，保留原站侧栏的分组与操作。原站页头图标仍可查看通知和聊天。
- 右侧每楼标注发布时间，使用浏览器本地时区。点击分支旁的加减号可折叠或展开，点击「回复 #楼层」能定位到已加载的被回复楼层。
- 长帖可分批加载回复；点击楼层编号可打开原站对应楼层。
- 使用当前浏览器里的 Linux.do 登录状态。点右侧书签图标会在原站添加或取消主题收藏，点铃铛可以设置该主题的通知级别。「关注」会汇总原站正在关注或跟踪的话题。
- 点页头「原版」返回论坛，再点「阅读器」可继续阅读同一篇话题。阅读区内也可按 `Esc` 返回。此切换只影响当前页面；刷新或再次打开浏览页时仍默认阅读器。顶部「配色」提供「跟随 Linux.do」「浅色」和「深色」。跟随模式同步原站颜色。固定浅色或深色覆盖整个网页，切回原版时恢复原站配色。
- 话题标题支持 `⌘/Ctrl + 点击`、中键和 Shift 点击，沿用浏览器的新标签页/新窗口行为。普通点击在右侧阅读。
- 登录后，阅读器按原站协议上报前台可见楼层的实际停留时间。首次读到楼层会及时同步，后续每 10 秒、切换话题、返回原版或离开页面时提交待同步时间；成功后刷新阅读器与原站的未读标记。后台标签页、折叠/屏幕外楼层、休眠和 3 分钟无操作不累计。
- 「已读楼层 / 阅读时长」与「话题浏览量」是不同的统计。阅读器在实际阅读后登记一次话题浏览，原站仍按自己的账号/IP 去重、统计限制和异步处理计数，重复打开或 `⌘ + 点击` 不保证每次都增加 1。

扩展程序只在 `https://linux.do/` 上运行。阅读数据从论坛接口获取，收藏和话题通知设置在点击对应控件时写入原站账号。

## 开发与发布

仓库根目录可以直接作为未打包的扩展目录加载。扩展使用原生 JavaScript 和 CSS，无需安装依赖。

`python3 scripts/package.py` 会在 `dist/` 中生成安装和 Chrome Web Store 上传用的 ZIP。打包包含运行时文件、许可证与使用/隐私说明，`manifest.json` 位于 ZIP 根目录。

`node --test tests/reading.test.mjs` 运行无第三方依赖的阅读追踪、请求协议、路由和桥接回归测试。
