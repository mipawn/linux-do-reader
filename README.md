# LINUX DO 阅读器

适用于 ego lite、Chrome 和 Edge 的第三方浏览器扩展。左边浏览话题，右边阅读主帖和按回复关系展开的楼层。

## 安装

1. 解压 `linux-do-reader.zip`。在 macOS 上，可以把解压后的文件夹放在 `~/Library/Application Support/Linux DO Reader`，目录里应直接包含 `manifest.json`。
2. 在 ego lite 或 Chrome 打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`。
3. 打开「开发者模式」，点「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。在 macOS 的文件选择窗口可以用 `⌘⇧G` 输入目录路径。
4. 打开或刷新 Linux.do。论坛页头有「阅读器 / 原版」切换，也可从浏览器扩展菜单打开阅读器。

ZIP 可以在解压后删除。浏览器会从选中的文件夹读取扩展文件，需要保留该文件夹。移动安装目录时，先停用旧条目，再加载新位置。确认新版可用后，可以移除旧条目并删除旧目录。

以后更新时，把新版文件覆盖到已经加载的固定目录。在扩展管理页点该扩展的「重新加载」，然后刷新 Linux.do。

## 使用

- 顶部可切换话题、收藏、关注。类别和标签可组合筛选，按 `/` 聚焦搜索框。
- 阅读器顶部的社区、资源、类别、标签来自原站侧栏。「原站导航」保留完整侧栏的分组、个人链接和操作。原站页头图标仍可查看通知和聊天。
- 右侧每楼标注发布时间，使用浏览器本地时区。点击分支旁的加减号可折叠或展开，点击「回复 #楼层」能定位到已加载的被回复楼层。
- 长帖可分批加载回复；点击楼层编号可打开原站对应楼层。
- 使用当前浏览器里的 Linux.do 登录状态。点右侧书签图标会在原站添加或取消主题收藏，点铃铛可以设置该主题的通知级别。「关注」会汇总原站正在关注或跟踪的话题。
- 点页头「原版」返回论坛，再点「阅读器」可继续阅读同一篇话题。阅读区内也可按 `Esc` 返回。顶部「配色」提供「跟随 Linux.do」「浅色」和「深色」。跟随模式会同步原站的颜色，页面背景保持透明。

扩展程序只在 `https://linux.do/` 上运行。阅读数据从论坛接口获取，收藏和话题通知设置在点击对应控件时写入原站账号。

## 开发与发布

仓库根目录可以直接作为未打包的扩展目录加载。扩展使用原生 JavaScript 和 CSS，无需安装依赖。

`python3 scripts/package.py` 会在 `dist/` 中生成 Chrome Web Store 上传用的 ZIP。打包只包含运行时文件，`manifest.json` 位于 ZIP 根目录。
