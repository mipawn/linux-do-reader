# LINUX DO 阅读器

适用于 ego lite、Chrome 和 Edge 的第三方浏览器扩展。增强 Linux.do 话题列表；点击标题直接阅读树状讨论，可随时切换原版。

- **列表增强**：首页和话题列表页默认启用阅读器，保留原站导航、搜索、收藏和关注。
- **默认树状详情**：点击标题直接进入树状讨论；直接打开或刷新帖子详情也默认使用阅读器，可在页头切换「原版」。
- **回复树**：不设单独的树状讨论入口。支持折叠、删除占位和最早 / 最新 / 最多赞排序。
- **可靠分页**：IntersectionObserver 底部哨兵触发，滚动和尺寸变化兜底；失败展示原因和重试入口，不在后台无限等待。
- **不做阅读同步**：已移除扩展的阅读时间累计、上报、额外浏览登记和已读标记桥接，旧同步开关不再生效。

## 安装

1. 从[最新版本](https://github.com/mipawn/linux-do-reader/releases/latest)下载已发布的版本安装包并解压。当前源码版本为 1.7.0，是否已发布以 Releases 为准。在 macOS 上，可以把解压后的文件夹放在 `~/Library/Application Support/Linux DO Reader`，目录里应直接包含 `manifest.json`。
2. 在 ego lite 或 Chrome 打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`。
3. 打开「开发者模式」，点「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。在 macOS 的文件选择窗口可以用 `⌘⇧G` 输入目录路径。
4. 打开或刷新 Linux.do 的首页或列表页，默认进入阅读器。论坛页头有「阅读器 / 原版」切换，也可从浏览器扩展菜单打开阅读器。帖子详情默认树状阅读；登录、账号设置和发帖页保留原版。

ZIP 可以在解压后删除。浏览器会从选中的文件夹读取扩展文件，需要保留该文件夹。移动安装目录时，先停用旧条目，再加载新位置。确认新版可用后，可以移除旧条目并删除旧目录。

以后更新时，把新版文件覆盖到已经加载的固定目录。在扩展管理页点该扩展的「重新加载」，然后刷新 Linux.do。

## 使用

- 顶部可切换话题、收藏、关注。「最新」下拉可以换话题列表，「筛选」可组合类别和标签，按 `/` 聚焦搜索框。
- 顶部「原站导航」包含社区、资源、类别、标签和自定义项目，保留原站侧栏的分组与操作。原站页头图标仍可查看通知和聊天。
- **普通标题**点击即在阅读器内打开树状讨论，保留 `⌘/Ctrl + 点击`、中键和右键打开原站地址的能力；新标签页的详情也默认树状阅读。
- 不自动读取列表第一篇，点击话题后桌面显示双栏树状讨论；「返回列表」关闭讨论，停止其未完成请求。
- 树中每楼标注发布时间，使用浏览器本地时区。分支旁的加减号可折叠或展开，点击「回复 #楼层」可定位父楼层，楼层编号打开原站对应位置。
- 回复可按「最早」「最新」「最多赞」排序，作用于同级分支并递归应用。**排序仅基于已加载回复**，后续加载可能调整顺序；不是全帖的服务端排名。
- 已删除楼层显示 `[已删除]` 和内容占位，保留子回复，不渲染其旧正文和作者身份。未返回的父楼层显示「未加载或不可用」，不误判为删除；数据返回后替换占位。
- 列表和已打开的树状讨论在接近底部约 300px 时按需加载；同一分页只发一个请求。正常新增内容不限制连续页数。连续三批没有新增可见内容或出现重复分页地址时，明确提示暂停，可点「加载更多」继续，避免无限请求空页或折叠分支。
- 阅读器 API 共用一个串行队列，请求开始至少间隔 1.1 秒，正文优先于元数据。HTTP 429、带 `Retry-After` 的 502/503/504 或 JSON 限流按服务端实际截止时间暂停；无截止信息的限流默认等待 5 秒。界面显示倒计时和重试按钮，不隐藏在「正在加载」后；截止时间在同站点标签页间共享。网络中断、无服务端截止时间的 502/503/504 读取最多恢复一次，写入不自动重放。
- 收藏和主题通知使用当前浏览器里的登录状态，只在点击控件时写入原站账号。「关注」汇总原站正在关注或跟踪的话题。
- 页头「原版」或阅读区内 `Esc` 返回论坛。此切换只影响当前页面；刷新或重新打开列表页仍默认阅读器，详情也默认树状阅读。页头「原版」可切换回 Linux.do 原始详情。
- 顶部「配色」提供「跟随 Linux.do」「浅色」「深色」。固定配色只在阅读器显示时覆盖网页，回原版后恢复原站配色。

扩展只在 `https://linux.do/` 上运行。扩展自身不发送阅读时间或额外浏览登记，原生详情的阅读记录和统计由 Linux.do 处理。

## 开发与打包

仓库根目录可以直接作为未打包的扩展目录加载。扩展使用原生 JavaScript 和 CSS，无需安装依赖。

`python3 scripts/package.py` 会在 `dist/` 中生成安装包，包含运行时文件、许可证与使用/隐私说明，`manifest.json` 位于 ZIP 根目录。该命令只打本地包，不发布 Release。

`node --test tests/*.test.mjs` 运行无第三方依赖的路由、默认树状导航、同步移除、回复树、统一请求队列、限流和 Observer 分页回归测试。
