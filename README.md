# LINUX DO 阅读器

适用于 ego lite、Chrome 和 Edge 的第三方浏览器扩展。左边浏览话题，右边阅读主帖和按回复关系展开的楼层。

- **默认阅读器**：打开或刷新 Linux.do 浏览页即可阅读，随时切回原版。
- **可选阅读同步**：默认关闭额外上报；按需开启，按可见楼层批量同步原站阅读进度，不刷阅读量。
- **双栏与回复树**：浏览话题、阅读回复、收藏和管理关注。
- **自动加载**：话题列表和回复区滚动接近底部自动加载，失败时可手动重试。原站通知和聊天入口保持可用。

## 安装

1. 从[最新版本](https://github.com/mipawn/linux-do-reader/releases/latest)下载版本安装包（例如 `linux-do-reader-1.6.2.zip`）并解压。在 macOS 上，可以把解压后的文件夹放在 `~/Library/Application Support/Linux DO Reader`，目录里应直接包含 `manifest.json`。
2. 在 ego lite 或 Chrome 打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`。
3. 打开「开发者模式」，点「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。在 macOS 的文件选择窗口可以用 `⌘⇧G` 输入目录路径。
4. 打开或刷新 Linux.do 的首页、话题或列表页，默认进入阅读器。论坛页头有「阅读器 / 原版」切换，也可从浏览器扩展菜单打开阅读器。登录、账号设置和发帖等操作页保留原版。

ZIP 可以在解压后删除。浏览器会从选中的文件夹读取扩展文件，需要保留该文件夹。移动安装目录时，先停用旧条目，再加载新位置。确认新版可用后，可以移除旧条目并删除旧目录。

以后更新时，把新版文件覆盖到已经加载的固定目录。在扩展管理页点该扩展的「重新加载」，然后刷新 Linux.do。

## 使用

- 顶部可切换话题、收藏、关注。「最新」下拉可以换话题列表，「筛选」可组合类别和标签，按 `/` 聚焦搜索框。
- 顶部「原站导航」包含社区、资源、类别、标签和自定义项目，保留原站侧栏的分组与操作。原站页头图标仍可查看通知和聊天。
- 右侧每楼标注发布时间，使用浏览器本地时区。点击分支旁的加减号可折叠或展开，点击「回复 #楼层」能定位到已加载的被回复楼层。
- 话题列表和长帖回复都会在滚动接近底部时自动分批加载，每轮最多连续预取两批；页面高度没有增加时暂停，继续滚动或点「手动加载更多」即可继续。请求共用单个队列，开始时间至少间隔 1.1 秒，正文优先于元数据和阅读同步。遇到 HTTP 429 / 503 时按服务器的 `Retry-After` 或 `wait_seconds` 统一等待（至少 30 秒），内容读取最多自动恢复一次，失败后保留手动重试。限流截止时间在同站点标签页间共享；此节流只管理阅读器 API，不控制原站、其他标签页或媒体资源的请求。点击楼层编号可打开原站对应楼层。
- 使用当前浏览器里的 Linux.do 登录状态。点右侧书签图标会在原站添加或取消主题收藏，点铃铛可以设置该主题的通知级别。「关注」会汇总原站正在关注或跟踪的话题。
- 点页头「原版」返回论坛，再点「阅读器」可继续阅读同一篇话题。阅读区内也可按 `Esc` 返回。此切换只影响当前页面；刷新或再次打开浏览页时仍默认阅读器。顶部「配色」提供「跟随 Linux.do」「浅色」和「深色」。跟随模式同步原站颜色。固定浅色或深色覆盖整个网页，切回原版时恢复原站配色。
- 点击话题标题直接在右侧阅读，不设置阅读器内的 `⌘/Ctrl + 点击` 新标签页功能。
- 阅读同步默认关闭，阅读区顶部「阅读同步：关」可一键开启，偏好保存在当前浏览器。关闭时不累计或上报阅读时间、不额外登记话题浏览，也不由阅读器更新原站已读标记；关闭会丢弃未发送时间，并取消尚未完成的同步请求（服务器已经收到的请求无法撤销）。开启且登录后，只累计前台可见楼层的实际停留时间，每 30 秒批量提交，不再因新楼层出现立即上报。切换话题、返回原版或离开页面时也遵守同一发送间隔、单请求限制和服务端退避；离开页面时不足间隔的尾部时间可能未保存。服务器确认后才移除未读蓝点并更新原站已读标记。置顶文字和回复树灰色连接点不代表未读。后台标签页、折叠/屏幕外楼层、休眠和 3 分钟无操作不累计。
- 个人「已读帖子数」只统计首次读过的不同帖子，同一楼层重看不会重复增加；「已读话题数」也按不同话题去重。Discourse 的个人摘要默认有最长 1 小时的服务端缓存，因此真实阅读已经保存，个人资料里的总数仍可能暂时不变。扩展不会伪造这些总数或重复刷请求。
- 「已读帖子 / 阅读时长」与「话题浏览量」是不同的统计。开启同步后，阅读器在实际阅读后登记一次话题浏览，原站仍按自己的账号/IP 去重、统计限制和异步处理计数，重复打开不保证每次都增加 1。

扩展程序只在 `https://linux.do/` 上运行。阅读数据从论坛接口获取，收藏和话题通知设置在点击对应控件时写入原站账号。

## 开发与发布

仓库根目录可以直接作为未打包的扩展目录加载。扩展使用原生 JavaScript 和 CSS，无需安装依赖。

`python3 scripts/package.py` 会在 `dist/` 中生成安装和 Chrome Web Store 上传用的 ZIP。打包包含运行时文件、许可证与使用/隐私说明，`manifest.json` 位于 ZIP 根目录。

`node --test tests/*.test.mjs` 运行无第三方依赖的阅读追踪、统一请求队列、限流退避、同步开关、路由、桥接和自动加载回归测试。
